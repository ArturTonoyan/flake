# Flake

Снег на рабочем столе macOS: сугробы на окнах и Dock, снежки, снеговик. Приложение живёт в строке меню (без иконки в Dock).

## Установка на другом Mac (без терминала)

Скачай только приложение (весь репозиторий не нужен):

**[Flake.dmg](https://github.com/ArturTonoyan/flake/releases/latest/download/Flake.dmg)** · [все релизы](https://github.com/ArturTonoyan/flake/releases)

1. Открой скачанный `Flake.dmg`.
2. Перетащи **Flake** в папку **Программы** (Applications).
3. Открой **Программы** → **Flake**.
4. Если macOS заблокирует запуск: **Системные настройки → Конфиденциальность и безопасность** → внизу **«Всё равно открыть»**.
5. Для сугробов на окнах включи **Запись экрана** для Flake в тех же настройках, затем перезапусти приложение.

После этого Flake запускается из Spotlight (`⌘Space` → Flake) или Launchpad. Терминал не нужен.

## Сборка у себя (тоже без ручного терминала)

Нужны macOS 13+ и [Xcode Command Line Tools](https://developer.apple.com/xcode/) (`xcode-select --install` один раз).

В Finder дважды кликни:

**`Собрать и установить.command`**

Скрипт соберёт приложение, поставит в «Программы», откроет его и положит готовый диск **`dist/Flake.dmg`** — его можно скинуть другу.

### Из терминала (если удобнее)

```bash
./scripts/make-dmg.sh          # → dist/Flake.dmg + Flake.app
open dist/Flake.dmg            # проверить установщик
# или сразу к себе:
cp -R ./Flake.app /Applications/ && open /Applications/Flake.app
```

Сборка — универсальная (`arm64` + `x86_64`), подходит и для Apple Silicon, и для Intel.

## Остановить

Меню снежинки в строке меню → **Выход**.

## Меню

- пауза / продолжить
- интенсивность снега
- реакция на мышь
- снежки по Wi‑Fi (локальная сеть)
- растаять весь снег
- выход

## Снежки по Wi‑Fi

Без аккаунтов и серверов: Mac в одной сети находят друг друга через Bonjour по **локальному Wi‑Fi/Ethernet** (не через интернет и не через VPN-туннель).

1. В меню снежинки включи **Снежки по Wi‑Fi**
2. Разреши доступ к локальной сети, если macOS спросит
3. В подменю видно, кто сейчас онлайн
4. Для каждого пира можно выбрать сторону: **Авто / Слева / Справа**
5. Слепи снежок и кинь его **за левый или правый край экрана** — он вылетит у друга с противоположной стороны

VPN можно оставить включённым: поиск и снежки идут по Wi‑Fi, а не в туннель. Нужно, чтобы оба были в **одной обычной Wi‑Fi-сети** (не гостевой) и у VPN не была включена блокировка локальной сети (LAN / «Allow local network»).

Безопасность: только UDP фиксированного размера, пакеты принимаются лишь от пиров из Bonjour, с HMAC и лимитом частоты. Фичу можно полностью выключить в меню — слушатель тогда не работает.
