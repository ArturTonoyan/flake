# Flake

Снег на рабочем столе macOS: сугробы на окнах и Dock, снежки, снеговик. Приложение живёт в строке меню (без иконки в Dock).

## Требования

- macOS 13+
- Xcode Command Line Tools (`xcode-select --install`)
- Apple Silicon (сборка по умолчанию под `arm64`)

## Сборка и запуск

В Terminal:

```bash
cd /path/to/flake
./scripts/build.sh
open ./Flake.app
```

Скрипт соберёт бинарник и положит готовое приложение в корень репозитория: `Flake.app`.

### Поставить как обычное приложение

Скопировать в «Программы»:

```bash
./scripts/build.sh
cp -R ./Flake.app /Applications/
open /Applications/Flake.app
```

После этого Flake можно запускать из Spotlight (`⌘Space` → Flake) или из Launchpad.

### Остановить

- Через меню снежинки в строке меню → **Выход**, или
- из Terminal:

```bash
pkill -x Flake
```

## Разрешение «Запись экрана»

Чтобы сугробы появлялись на окнах, macOS должна отдавать рамки окон:

1. Открой **Системные настройки → Конфиденциальность и безопасность → Запись экрана**
2. Включи доступ для **Flake**
3. Перезапусти приложение

Без этого снег может идти, но сугробы на окнах не появятся.

## Меню

Иконка снежинки в строке меню:

- пауза / продолжить
- интенсивность снега
- реакция на мышь
- растаять весь снег
- выход

## Пересборка после изменений

```bash
./scripts/build.sh && open ./Flake.app
```

Если старый процесс ещё запущен:

```bash
pkill -x Flake 2>/dev/null; ./scripts/build.sh && open ./Flake.app
```
